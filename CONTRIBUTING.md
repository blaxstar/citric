# Contributing

Thanks for your interest in citric. **This repository is a read-only mirror**
of the citric source, published with `citric publish`; development happens
on a citric server, and pull requests here are closed without being merged.

What helps right now:

- **Issues** — bug reports with steps to reproduce, and feature requests,
  are very welcome.
- **Security problems** — please report them privately; see
  [SECURITY.md](SECURITY.md).

Contributions by pull request may open later; this file will say so when they
do.
