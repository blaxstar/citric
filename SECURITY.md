# Security policy

Please report vulnerabilities privately through GitHub:
**Security → Report a vulnerability** on
[blaxstar/citric](https://github.com/blaxstar/citric/security/advisories/new).
Don't open a public issue for them.

Include what you found, how to reproduce it, and the CitriC version
(`citric version`). We'll acknowledge the report, keep you updated, and credit
you in the release notes unless you'd rather we didn't.

Supported versions: the latest release.
